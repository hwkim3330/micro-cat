# MICRO CAT — Rev 1

**소유자 hwkim3330이 제작·판매를 목표로 개발하는 상업용 독자 설계 소형 두발 로봇.** 둥근 머리, 쉘과 한 몸인 귀, 말려 올라간 꼬리, 뒤로 길어진 앞발. Microduck의 14축 정책 인터페이스(61 관측 → 14 행동, 50 Hz)를 그대로 쓰되 기구·외장·서보 배치·전장 자리는 독자 설계입니다.

관련 저장소: [Micro X](https://github.com/hwkim3330/micro-x)(티렉스 계열, 같은 도구·같은 소유자) · [Micro Rex](https://github.com/hwkim3330/micro-rex)(원본 기구를 그대로 쓰는 **비상업** 비교 시험기) · [micro-cat-fly](https://github.com/hwkim3330/micro-cat-fly)(고정된 초파리 커넥톰으로 목표 방향 명령을 만드는 **비상업** 연구 저장소).

**현재 단계: Rev 1 구동 설계 · 디지털 검증. 실물 출력·조립·보행·내구 시험은 아직 없습니다. 판매 가능한 완제품이 아닙니다.**

## 이 저장소가 주장하는 것과 주장하지 않는 것

주장하는 것은 **측정된 것뿐**입니다. 아래 표의 모든 숫자는 `artifacts/`의 JSON에서 `tools/report.py`가 자동으로 채워 넣으며, 모델 SHA256에 묶여 있어 형상을 바꾸면 검사 결과가 먼저 깨집니다. 문서에 손으로 적은 성능 숫자는 없습니다.

주장하지 않는 것: 실물 보행, 내구성, 원가 경쟁력. 특히 원가는 [docs/COST.md](docs/COST.md)에 기록된 대로 **15개 소매 서보 값만으로도 완제품 $399를 넘습니다.** 부품값으로 이기는 물건이 아닙니다.

## micro-x에서 바뀐 것

| | micro-x Rev C | Micro Cat Rev 1 | 이유 |
|---|---|---|---|
| 형상 | 둥근 머리 + 넓은 부리 | 둥근 두개골 + 짧은 입, 통짜 귀, 말린 꼬리 | 부리를 남기면 계속 오리로 읽힘 |
| 귀 | 없음 | 지붕에서 자라난 통짜 핀 | 별도 부품·얇은 목 없이 실루엣을 만드는 유일한 방법 |
| 앞발 | 평평한 바닥판만 | 같은 바닥판 + **1.0 mm 뜬 뒤꿈치 돌기** (뒤로 24 mm) | 아래 "가장 약한 축" 참조 |
| 고관절 브래킷 윗면 | 평면으로 절단 | **롤 축 ±0.35 rad 회전 포락선**으로 절단 | 평면이면 바깥 리브가 몸통 스커트에 걸려 롤이 +5.7°에서 멈춤 |
| 카메라 | x 70 | x 60 | 두개골을 122 → 108 mm로 줄이기 위해. 대가로 코 보어가 깔때기가 되어 실효 화각 약 60° |
| 발 접촉 박스 | 하드코딩 (x −52…2) | **발바닥 메시에서 산출** | 하드코딩이면 늘린 발이 물리 모델에 반영되지 않음 |

## 가장 약한 축은 "뒤로 넘어짐"이었습니다

HOME 자세에서 무게중심이 지지영역을 벗어나기까지의 정적 각도입니다(`tools/tip_study.py`, 강체·정적·접촉 모델 없음).

머리가 무겁고 발이 앞으로만 길어서 뒤쪽 지지 거리가 짧습니다. 대응은 바닥판 뒤로 **1.0 mm 떠 있는 뒤꿈치 돌기**입니다 — 평지에서는 안 닿고 뒤로 3.2° 기울면 닿습니다. 바닥판 자체는 기준 발과 같은 58 mm입니다.

<!-- measured:spur -->
| 뒤꿈치 돌기 높이 | 뒤로 기울기 | 앞으로 |
|---|---|---|
| no spur | 4.65° | 18.9° |
| 0.5 mm | 14.5° | 18.9° |
| 1.0 mm | 14.55° | 18.9° |
| 1.5 mm | 4.65° | 18.9° |
<!-- /measured -->

돌기를 1.5 mm로 올리면 **닿기 전에 넘어져서 효과가 0**입니다. 이번 설계에서 유일하게 취향이 아니라 측정에 근거한 변경입니다.

## 측정된 가동 범위

## 설계 개요

- **관절**: 좌우 고관절 요·롤·피치, 무릎, 발목(10) + 목 피치, 머리 피치·요·롤(4) + 턱(1).
- **피벗·축**: `engineering/functional_layout.json` (기준 로봇을 qpos 0에서 측정한 기능 치수). 서보 몸체 방향만 두 곳에서 바꿨고 이유를 같은 파일에 적었습니다.
- **서보**: XL330급. 인터페이스 치수와 발주 전 확인 항목은 `engineering/actuator_interface.json`. 케이스 홀 패턴은 아직 모델에 없습니다.
- **패키징**: 2S 18650급 배터리는 꼬리 커버 안, 보드(최대 50 × 27 mm)는 고관절 서보 위 데크, 카메라는 코 안.
- **떨어질 부품 없음**: 귀·눈·코는 전부 쉘과 한 몸이고 도색으로 마감합니다. 손·발톱·수염 없음.
- **설계 자세**는 `qpos = 0`(다리를 곧게 편 자세)이라 모든 관절 축이 X·Y·Z에 정렬되고 브래킷이 평평하게 출력됩니다. 정책의 HOME 각도는 기구에 굳히지 않습니다.

## 재생성

```sh
uv venv .venv && uv pip install --python .venv/bin/python -r requirements.txt
.venv/bin/python cad/build.py          # 20개 부품 STEP/STL/GLB + artifacts/parts.json
.venv/bin/python tools/travel.py       # 실측 가동 범위 (수십 분)
.venv/bin/python cad/compat_model.py   # models/micro_cat_14.xml, rig.json, 제어 계약
.venv/bin/python tools/interference.py # 정적 겹침 + 관절별 스윕
.venv/bin/python tools/printability.py # 침대 적합·오버행·접촉 면적
.venv/bin/python tools/balance.py tools/tip_study.py
.venv/bin/python tools/report.py       # 위 결과를 README와 docs/DESIGN.md에 반영
```

정책 평가는 별도 환경입니다:

```sh
uv venv --python 3.12 .venv-policy && uv pip install --python .venv-policy/bin/python -r requirements-policy.txt
.venv-policy/bin/python tools/fetch_compat.py
MUJOCO_GL=disable .venv-policy/bin/python tools/evaluate_compat.py --seconds 10 --seeds 3
```
